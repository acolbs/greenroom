# Product

## Register

product

## Users
NBA fans who want to play GM. They pick any of the 30 franchises and run the full offseason: resolving contracts, navigating free agency, executing a 2-round draft, and building toward a championship-caliber roster for the 2026-27 season. They care about roster construction, salary cap strategy, and draft scouting. Context is a focused solo session — think "one more offseason" energy.

## Product Purpose
Greenroom is an NBA offseason GM simulator. It exists to let fans experience the decision-making that shapes a real franchise's future — cap management, player evaluation, draft strategy — in a streamlined 4-step flow. Success looks like a user finishing a full offseason run and immediately wanting to try another team.

## Brand Personality
Clean, Confident, Premium. The interface should feel like a polished front-office tool — authoritative without being sterile, refined without being cold. The tone is knowledgeable and direct, like a trusted scout briefing you before a decision.

## Anti-references
- **ESPN / Yahoo Fantasy**: cluttered, ad-heavy, legacy sports UI with too many panels, colors, and competing CTAs
- **Generic SaaS dashboards**: bland corporate tool feel — gray everything, no personality, could be any product
- **Flashy sports betting apps**: neon, aggressive, DraftKings/FanDuel gambling aesthetic with attention-hijacking patterns

## Design Principles
1. **War room clarity** — every screen is a GM's command center. Dense data, clean hierarchy, zero noise.
2. **Earned confidence** — the UI feels authoritative because the craft is precise, not because it's loud.
3. **Flow over features** — the 4-step offseason path should feel seamless. Never break the GM fantasy.
4. **Show, don't decorate** — stats, scores, and roster data ARE the visual interest. Ornament serves legibility.
5. **Insider's edge** — make casual fans feel like front-office insiders without overwhelming them.

## Accessibility & Inclusion
Minimal for now — focus on the core experience. Maintain reasonable contrast ratios and keyboard navigability for primary flows. Reduced-motion alternatives are already in place. Enhanced accessibility can be layered in later.
